# Deskripsi Aplikasi

EndemikDB merupakan aplikasi Android yang dirancang untuk memberikan informasi mengenai hewan dan tumbuhan endemik Indonesia.

Aplikasi ini membantu pengguna mengenal keanekaragaman hayati Indonesia melalui informasi yang lengkap, fitur pencarian yang cepat, serta penyimpanan data favorit secara lokal menggunakan ROOM Database.

---

# Fitur Aplikasi

- Splash Screen
- Home Hewan Endemik
- Home Tumbuhan Endemik
- Pencarian Data Real-time
- Detail Informasi Endemik
- Favorit menggunakan ROOM Database
- Profil Pengembang
- Dark Mode & Light Mode
- Integrasi REST API menggunakan Retrofit

---

#  Teknologi yang Digunakan

- Java
- Android Studio
- Retrofit
- ROOM Database
- RecyclerView
- CardView
- Glide
- Material Design Components
